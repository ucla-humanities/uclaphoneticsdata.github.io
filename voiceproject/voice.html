Welcome to the home page of the "Production and Perception of Linguistic Voice Quality" project at UCLA. This project was funded by NSF grant BCS-0720304 to Prof. Pat Keating, with Prof. Abeer Alwan, Prof. Jody Kreiman of UCLA, and Prof. Christina Esposito of Macalester College, for 2007-2012.

Below you will find links to spreadsheet files with measures gathered using Voicesauce (Shue, Keating, Vicenik & Yu 2011) for both acoustic measures and EGG measures. The accompanying readme file provides information on the various coding used in both spreadsheets.

You will also find links to Audio and Textgrid files for all languages studied in the project. Where available, EGG files are also available for download. Each language has an accompanying 'Notes' document and wordlist. The 'Notes' document provides information about the speakers recorded and filenaming conventions used for the individual languages, and credits for data collection.
